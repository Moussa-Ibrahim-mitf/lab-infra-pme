# Lab infrastructure PME : MTF Consulting

Lab personnel où je conçois et administre, pas à pas, l'infrastructure réseau et systèmes d'une PME fictive : **MTF Consulting**, 2 sites (Rabat et Salé), environ 50 employés.

Objectif : mettre en pratique l'administration des réseaux et des systèmes, et documenter chaque étape (schémas, configurations, procédures).

## Modules
| Dossier | Contenu | État |
|---|---|---|
| `01-reseau` | Réseau Cisco (Packet Tracer) : VLAN, trunk, routage inter-VLAN, OSPF, ACL, NAT, DHCP, IPv6 | 🔜 à venir |
| `02-windows` | Windows Server 2022 : Active Directory, DNS, DHCP, GPO, partages, scripts PowerShell | 🔜 à venir |
| `03-securite` | pfSense : pare-feu, DMZ, VPN IPsec entre les sites, OpenVPN, durcissement (guides ANSSI) | 🔜 à venir |
| `04-linux` | Ubuntu Server 24.04 : SSH, utilisateurs et droits, systemd, LVM, Nginx, BIND, Samba, Bash | 🔜 à venir |
| `05-automatisation` | Ansible, supervision Zabbix, sauvegardes et plan de reprise | 🔜 à venir |
| `docs` | Plan d'adressage IP, schémas réseau, procédures | 🔜 à venir |

## Environnement
VirtualBox sur un PC de 16 Go de RAM, Cisco Packet Tracer, GNS3, Wireshark.
